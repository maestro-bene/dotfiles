# macOS

Apple Silicon et Intel sont pris en charge. Si les outils Apple ne sont pas déjà installés : `xcode-select --install`.

Suivez les [étapes d’installation](../README.md#installation). L’installateur principal installe Homebrew s’il manque; aucune installation manuelle préalable de Homebrew n’est nécessaire. Il installe les outils du manifeste commun et du backend choisi, mais pas Ghostty (optionnel, décrit par `Brewfile.personal`).

Pour les actions à faire après l’application (Mise, Fish, Television, Pi agent, Neovim et backend), voir [Après l’application](../README.md#après-lapplication). Les polices, le presse-papiers et les fonctions graphiques dépendent du terminal utilisé.
